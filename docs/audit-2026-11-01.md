  (`/api/health → ok | db=down | servingSpa=true`، `/` = 200، `/packages` = 200).

  `findMany` بدون `take`، هندلرهای تغییردهندهٔ بدون guard، سرشماری placeholderهای `deploy/`،
  تست‌های زندهٔ `awk`/`bash` روی `read_env` و `set -euo pipefail`، بررسی `git check-ignore` و
  `git ls-files`.
- بازبینی خط‌به‌خط منبع برای هر مورد با علامت ✓.

سنجیده‌نشده (پس ادعایی نداریم):

- PostgreSQL لوکال (`:5433`) پایین است → هیچ تست پایانه‌ای روی داده واقعی انجام نشد؛ صحت
  صفحه‌بندی از روی کد و harness است نه رفتار runtime.

  از متن Dockerfile + وجود/عدم‌وجود فایل‌ها استخراج شده (B4 قابل بازتولید در build نیست ولی
  sitemap غلط **در دیسک اثبات شده**).
- رندر واقعی UI ادمین: در dev اعتبارنامهٔ سوپرادمین نیست و `/admin` به `/login` می‌رود، پس
  پنل‌ها فقط تا «کامپایل + بیلد» بررسی شده‌اند.
